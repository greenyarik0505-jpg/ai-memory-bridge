## ⚡ Inicio Rápido

### 1. Instalar en un comando

```bash
npx skills add greenyarik0505-jpg/ai-memory-bridge
```

### 2. Habla con tu agente IA en lenguaje natural

- **"Recuerda este proyecto"** / **"Remember this project"** → Inicializa `.ai-memory/`, escanea automáticamente el stack del proyecto (`scan.py`) y guarda objetivos y restricciones.
- **"Guarda nuestro progreso"** / **"Save our progress"** → Registra decisiones de arquitectura, tareas completadas y pendientes, escanea secretos y deduplica entradas.
- **"Prepara el traspaso para Codex"** / **"Prepare a handoff for Codex"** → Genera `.ai-memory/handoffs/handoff-codex.md` y sincroniza `AGENTS.md` sin sobrescribir tus reglas manuales.
- **"Continúa donde lo dejó Claude Code"** → Recupera el estado completo del proyecto al instante.

Consulta la documentación completa en el [README principal](../../README.md).
