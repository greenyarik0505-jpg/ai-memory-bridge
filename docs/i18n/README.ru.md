## Зачем нужен AI Memory Bridge?

При разработке реальных проектов редко используется только один ИИ-агент: вы можете проектировать архитектуру в **Claude Code**, делегировать фоновые задачи в **OpenAI Codex**, дорабатывать интерфейс в **Cursor** и координировать мультиагентную проверку в **Google Antigravity**.

При каждом переключении между агентами **контекст теряется**:
- Забываются архитектурные решения и причины отказа от альтернатив.
- Приходится заново объяснять технические ограничения.
- Простые синхронизаторы правил перезаписывают ваши пользовательские `CLAUDE.md` или `.cursor/rules/`.

**AI Memory Bridge** решает эту проблему как нативный **Agent Skill (`SKILL.md`)** с детерминированным локальным движком на Python 3.10+ (без внешних зависимостей). Вы общаетесь со своим агентом на **любом языке** — агент сам запускает проверенные скрипты, сканирует секреты, устраняет дубликаты, находит противоречия и формирует готовый пакет передачи (`handoff`).

## ⚡ Быстрый старт

### 1. Установка одной командой

```bash
npx skills add greenyarik0505-jpg/ai-memory-bridge
```

### 2. Общайтесь с ИИ-агентом обычными фразами (на любом языке)

Вам не нужно вручную вводить CLI-команды. Просто напишите своему агенту:

- **«Запомни этот проект»** / **"Remember this project"** → Инициализирует `.ai-memory/`, автоматически сканирует стек и структуру проекта за 1 секунду (`scan.py`) и сохраняет цели и ограничения.
- **«Сохрани наш прогресс»** / **"Save our progress"** → Извлекает выполненные и текущие задачи, исправления багов и следующие шаги, проверяет отсутствие секретов и обновляет `.ai-memory/memory.json`.
- **«Подготовь передачу для Codex»** / **"Prepare a handoff for Codex"** → Генерирует пакет `.ai-memory/handoffs/handoff-codex.md` и безопасно обновляет блок `<!-- AI-MEMORY-BRIDGE:START -->` в `AGENTS.md`.
- **«Продолжи с того места, где остановился Claude Code»** → Читает сохранённую память проекта и продолжает работу без повторных объяснений.
- **«Открой панель памяти»** / **"Open memory dashboard"** → Генерирует интерактивную офлайн-панель `.ai-memory/dashboard.html` с переключением языков (`EN / RU / UK / ZH / ES / DE`).

## 🧠 Ключевые возможности

- **Единая локальная память (`.ai-memory/`)**: 9 типов записей (`goal`, `decision`, `constraint`, `preference`, `task_done`, `task_pending`, `bug_fix`, `next_step`, `session_summary`).
- **Мультиязычное ядро**: полная поддержка Unicode (кириллица, латиница, европейские языки и CJK) для поиска дубликатов, обнаружения логических конфликтов и ранжированного поиска BM25.
- **Автосканер проекта (`scan.py`)**: за 1 секунду определяет манифесты (`package.json`, `pyproject.toml`, `Cargo.toml`, `go.mod`, `pubspec.yaml`), фреймворки и команды сборки/тестов.
- **Контроль актуальности файлов (`check-stale`)**: автоматически предупреждает, если запись ссылается на удалённый или переименованный файл.
- **Автозахват Git-контекста (`auto-git`)** и учёт активной ветки Git (`branch-aware`).
- **Безопасность по умолчанию**: блокировка утечек API-ключей/токенов, защита от косвенных prompt-инъекций и защита от symlink/path-traversal атак.

Полная документация на английском языке доступна в [основном README.md](../../README.md).
